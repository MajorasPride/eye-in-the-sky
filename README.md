# Eye in the Sky (working title)

A zombie strategy game by MajorasPride where you cannot control the survivors. They decide for
themselves. You are the eye in the sky: mark what is safe, spot supplies, pick off zombies and
call in help so they make it to the stadium.

- **Status:** first playable prototype (Sacramento map, 4 levels, stadium holdout). Not live yet.
- **Run it:** download `index.html` and open it in a browser (phone or PC).
